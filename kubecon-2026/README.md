# I Rebuilt Agent Memory Three Times. The Third Time I Treated It Like Data.

KubeCon North America 2026 presentation by Artur Ciocanu.

- [Presentation](presentation/) — open the self-contained [HTML deck](presentation/deck.html).
- [Demo](demo/stage/) — the Hindsight flight-memory application used in the talk.
- [Experiments and evidence](demo/experiments/) — the Mem0, Letta V1, Letta Code, and Hindsight trials underlying the talk.

I ran these experiments to understand how different approaches handle memory, not to rank or dismiss the projects. The results describe small trials with specific configurations, not benchmarks or general claims about the products. See each report for the setup, actual results, and limitations.

Earlier drafts, research, rehearsal material, and local working files live in `archive/` on the original machine. That directory is ignored by Git and is not included in a clone.
