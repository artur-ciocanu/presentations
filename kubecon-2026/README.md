# I Rebuilt Agent Memory Three Times. The Third Time I Treated It Like Data.

My talk at KubeCon North America 2026.

- [Presentation](presentation/): open the self-contained [HTML deck](presentation/deck.html).
- [Demo](demo/stage/): the Hindsight flight-memory application I used in the talk.
- [Experiments and evidence](demo/experiments/): my trials with Mem0, Letta V1, Letta Code, and Hindsight.

I ran these experiments to understand how the different approaches handle memory. They're small trials with specific configurations, not benchmarks or a ranking of the projects. Each report includes the setup, results, and limitations.

I keep earlier drafts, research, and rehearsal material locally in `archive/`. That directory isn't included in this repository.
